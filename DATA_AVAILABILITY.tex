\section*{Data and code availability}
No experimental data were used. The syndrome update, comparison words,
recurrence coefficients, and rational enclosures are given in the paper.
The verification code is publicly available at
\url{https://github.com/chylonczyk/Reducing-the-cost-of-ancilla-purification-for-Majorana-quantum-computation}.
The accompanying archive \texttt{majorana\_verification.zip} contains
Python scripts for the integer and rational certificates, the
independent recurrence checks, the controlled fourth-stage comparison,
and the numerical resource and effective-noise calculations. A README
specifies the dependencies and commands needed to reproduce these
calculations. The noise-continuation values are numerical, whereas the
stated noiseless basin-entry bounds are certified by exact arithmetic.
